# دليلي — تطبيق أندرويد محلي بالكامل

كتالوج علاجات وتحاليل شخصي. **لا يتصل بأي خادم أو رابط ويب إطلاقًا** — كل
الملفات (HTML/JS) مدمجة داخل حزمة التطبيق نفسها (`app/src/main/assets/`)،
وكل البيانات تُخزَّن في **قاعدة بيانات SQLite محلية على الجهاز**. لا صلاحية
إنترنت في التطبيق أصلًا.

## 📦 ملف APK جاهز

الملف مبني ومُوقَّع وجاهز للتثبيت مباشرةً بلا أي أدوات:

**رابط التحميل المباشر** (اسم ثابت لا يتغيّر مع الإصدارات):

```
https://github.com/alaoufi/Lab_tr/raw/HEAD/dist/dalili.apk
```

افتحه من متصفح الجوال مباشرةً فينزل الملف، ثم اضغطه لتثبيته.

| الملف | الإصدار | الحجم |
|---|---|---|
| `dist/dalili.apk` | ٢٫٥ | ~1.8 MB |

لمعرفة النسخة المثبّتة عندك: **⚙️ الإعدادات ← حول ← إصدار التطبيق** — الرقم
مقروء من الحزمة نفسها فيتغيّر وحده مع كل تحديث.

فعّل «السماح بالتثبيت من مصادر غير معروفة» إن طلب النظام ذلك. لبناء نسخة
جديدة بنفسك بعد أي تعديل، اتبع الخطوات في قسم البناء أدناه.

## 🧭 التنقل

**صفحة رئيسية** فيها أقسامك — العلاجات، التحاليل، الأشعة والفحوصات،
الوصفات العلاجية، وما تضيفه أنت — كل بطاقة تعرض عددها، وفوقها ملخّص السلة
إن كان فيها شيء. ترتيب البطاقات وأسماؤها وأيقوناتها كلها بيدك.
المكتبة الجاهزة والإضافة السريعة داخل **الإعدادات** لأنهما لا تُستخدمان
باستمرار، والإعدادات نفسها في ترس الترويسة.

**كل صفحة داخلية فيها سهم رجوع** (→) في الترويسة، والعنوان يتغيّر بحسب
الصفحة. سهم الرجوع يتبع مسارك فعلًا: من دخل المكتبة من الإعدادات يعود
للإعدادات، ومن دخلها من الرئيسية يعود للرئيسية.

**زر الرجوع في الجهاز** يعمل بنفس المنطق: يغلق النافذة المنبثقة أولًا إن
كانت مفتوحة، ثم يرجع صفحة، وإذا كنت في الرئيسية يخرج من التطبيق.

## 🗄️ قاعدة البيانات المحلية

قاعدة SQLite داخل مساحة التطبيق الخاصة:
`/data/data/me.alaoufi.dalili/databases/dalili.db` — لا يصل إليها أي تطبيق
آخر ولا تُرسَل لأي جهة.

| الجدول | المحتوى |
|---|---|
| `meds` | العلاجات (الاسم التجاري/العلمي، التصنيف، التركيز، الجرعات، المدة، الاستخدامات، المحاذير، الملاحظات) |
| `labs` | التحاليل (التصنيف/التخصص، الاسم، الرمز، الهدف، المتطلبات، الممنوعات، شائع؟) |
| `recipes` | الوصفات (التصنيف، الاسم، النوع، الهدف، المواد، طريقة الإعداد، الاستخدام، الجرعة، المدة، الأعراض المتوقعة، الاحتياطات، مفضّلة؟) |
| `cart` | سلة التحديد لكل قسم مع ترتيبها |
| `cats` | التصنيفات: كيان مستقل لكل قسم باسمه وترتيبه |
| `sections` | الأقسام: الأربعة الأصلية وما تنشئه أنت، باسمها وأيقونتها وترتيبها |
| `fields` | الحقول الإضافية التي تعرّفها داخل بيانات العنصر |
| `items` | عناصر الأقسام التي تنشئها بنفسك |
| `groups` / `group_items` | المجموعات المسمّاة ومحتوى كل واحدة بترتيبه |
| `settings` | الإعدادات: بصمة رمز القفل (SHA-256)، والحقول المرسلة لكل قسم |

الطبقات: `DaliliDb.java` (الجداول والاستعلامات) ← `DbBridge.java` (جسر
JavaScript باسم `NativeDb`) ← `Store` في `app.js` (تناديه الواجهة).

**الترحيل:** من ثبّت إصدارًا سابقًا كان يحفظ في `localStorage` ستُنقل بياناته
تلقائيًا إلى قاعدة البيانات عند أول فتح، مرّة واحدة وبلا فقد شيء.

**لماذا قاعدة بيانات بدل `localStorage`؟** جداول حقيقية بمفاتيح وفهارس بدل نص
JSON واحد، الاستيراد يتم داخل معاملة واحدة (إمّا يكتمل أو تبقى البيانات
القديمة سليمة)، ولا تُفقد البيانات عند مسح ذاكرة WebView.

## 📋 المتطلبات
- جهاز **كمبيوتر** (وليس جوالًا) — Windows أو Mac أو Linux
- برنامج **Android Studio** (مجاني): https://developer.android.com/studio
- اتصال إنترنت *على الكمبيوتر فقط* أول مرة (لتنزيل أدوات البناء) — التطبيق
  الناتج نفسه لن يحتاج إنترنت بعد ذلك أبدًا

## 🛠️ خطوات البناء (٥ دقائق تقريبًا)

1. ثبّت Android Studio وافتحه
2. **File ← Open** ← اختر مجلد `DaliliApp` (هذا المجلد نفسه)
3. انتظر حتى ينتهي "Gradle Sync" أسفل الشاشة (أول مرة قد تأخذ بضع دقائق —
   يُنزِّل Android Studio أدوات البناء تلقائيًا)
4. من القائمة العلوية: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**
5. عند الانتهاء تظهر رسالة صغيرة أسفل يمين الشاشة فيها رابط **locate** —
   اضغطه ليفتح مجلد الملف الناتج: `app/debug/app-debug.apk`
6. انقل هذا الملف لجوالك (عبر كابل، بلوتوث، أو أي وسيلة) وثبّته مباشرة
   (فعّل «السماح بالتثبيت من مصادر غير معروفة» إن طلب النظام ذلك)

> من سطر الأوامر مباشرةً (بلا Android Studio) يكفي:
> `./gradlew assembleRelease` بعد ضبط `local.properties` على مسار
> Android SDK — الناتج في `app/build/outputs/apk/release/`.

## 🌿 الوصفات العلاجية

القسم الثالث. لكل وصفة: **اسم الوصفة**، **نوعها** (علاجية / وقائية /
غذائية — بأزرار لا قائمة منسدلة)، **الهدف**، **المواد المستخدمة**،
**طريقة الإعداد**، **الاستخدام**، **الجرعة**، **مدة الاستخدام**،
**الأعراض المتوقعة**، **الاحتياطات**. تُجمَّع في القائمة حسب تصنيفها، ولها
سلة تحديد وطباعة ومشاركة كصورة مثل بقية الأقسام.

## 🗂️ الأقسام — تعديلها وإضافة قسم جديد

الأقسام ليست محفورة في التطبيق. من **⚙️ الإعدادات ← 🗂️ إدارة الأقسام**:

- **✏️ تسمية أي قسم وتغيير أيقونته** — بما فيها الأربعة الأصلية
- **⬆️ ⬇️ ترتيبها** — هو ترتيب البطاقات في الصفحة الرئيسية
- **➕ قسم جديد** كامل الصلاحيات: تصنيفاته، حقوله، سلّته، مجموعاته،
  معاينته، طباعته وإرساله — كالأقسام الأصلية تمامًا
- **🗑️ حذف** قسم أنشأته (الأصلية لا تُحذف)

القسم الجديد يبدأ بحقل «الاسم» فقط، وتبني بقيّته من «الحقول الإضافية».

## 🧩 الحقول الإضافية

تضيف ما تشاء من الحقول داخل بيانات العنصر في أي قسم — «الشركة المصنّعة»
للعلاجات، «المختبر المفضّل» للتحاليل، «عمر الجرعة» لقسم أنشأته. من
**إدارة الأقسام ← 🧩 الحقول الإضافية**: اسم الحقل ونوعه (سطر واحد أو نصّ
طويل)، مع ترتيب وإعادة تسمية وحذف.

الحقل يظهر في نموذج العنصر، **وعلى بطاقته في القائمة، وفي المعاينة
والطباعة والصورة والنص المنسوخ — من لحظة إنشائه بلا أي ضبط**. ولو أردت
إخفاءه من المُرسَل لاحقًا فمن **⚙️ الإعدادات ← الحقول المرسلة**. إعادة
تسمية الحقل لا تفقد ما كُتب فيه.

## 🏷️ التصنيفات

التصنيف كيان تملكه أنت، لا نصّ تكتبه مع كل عنصر: **العيون** و**الأذن** في
العلاجات، **كيمياء الدم** و**المناعة** في التحاليل، **الأشعة السينية**
و**الرنين المغناطيسي** في الأشعة — وداخل كلٍّ منها عناصره.

من زر **🏷️** في شريط أدوات أي قسم تفتح صفحة تصنيفاته:

- **➕ تصنيف جديد** — ولو قبل أن يكون فيه عنصر واحد
- **✏️ إعادة التسمية** — تنقل كل عناصره معه دفعةً واحدة
- **⬆️ ⬇️ الترتيب** — هو نفسه ترتيب المجموعات في القسم
- **🗑️ الحذف** — لا يحذف عنصرًا واحدًا؛ تعود عناصره «غير مصنّف»

وداخل نموذج أي عنصر تختار تصنيفه من **قائمة منسدلة** سطرًا واحدًا مهما
كثرت التصنيفات، وفيها خيار **➕ تصنيف جديد…** يكشف حقل اسمه فتنشئه بلا
مغادرة النموذج. التصنيف الفارغ يعيش في صفحته ولا يزحم القسم؛ يظهر هناك
حين يسكنه أول عنصر.

التصنيفات المبدئية مأخوذة من المكتبة الجاهزة نفسها، فالاستيراد منها لا
يُنشئ تصنيفات مكرّرة — وكلها قابلة لإعادة التسمية والحذف.

## 📁 المجموعات المسمّاة

قائمة جاهزة داخل القسم — «فحوصات ما قبل الجراحة» مثلًا — تُطبع أو تُرسَل
باسمها بضغطة، بلا إعادة تحديد في كل مرة. متاحة في كل قسم من زر
📁 في شريط الأدوات.

**الإنشاء:** إمّا «+ مجموعة جديدة» فارغة، أو «💾 مجموعة» من شريط السلة
فتتحوّل تحديداتك الحالية إلى مجموعة باسم تختاره.

**التعديل:** المحرّر يعمل على **نسخة مؤقتة** — تضيف عناصر (بمنتقٍ فيه
بحث، والموجود مسبقًا مقفل) وتحذف بـ✖️، ثم:

- **💾 حفظ** — يثبّت التعديل في قاعدة البيانات
- **👁️ عرض وإرسال** — يفتح المعاينة على القائمة المعدَّلة كما هي أمامك
  (والرجوع منها لا يمسّ تعديلاتك المؤقتة)
- **رجوع بلا حفظ** — يسأل أولًا، ثم **تعود المجموعة كما كانت** تمامًا

فتقدر تعدّل مجموعة لحالة مريض بعينه، ترسلها، وتخرج بلا أن تمسّ المجموعة
الأصلية. حذف المجموعة لا يحذف أي تحليل أو علاج — يحذف القائمة فقط.

## 👁️ المعاينة قبل الإرسال

لا شيء يُرسَل قبل أن تراه. من شريط السلة (أو من مجموعة محفوظة، أو من داخل
محرّر المجموعة) زر واحد: **👁️ عرض وإرسال** — يفتح صفحة معاينة فيها
تبويبان:

- **📄 الورقة** — نفس ورقة الـPDF والطباعة حرفيًا: الترويسة إن كانت مملوءة،
  العنوان، التاريخ، والعناصر بتنسيقها النهائي
- **🖼️ الصورة** — نفس اللوحة التي ستُرسَل فعلًا، لا تقريبًا لها

وأسفلها شريط إرسال ثابت: **📄 PDF** / **🖼️ صورة** / **🖨️ طباعة** /
**📋 نسخ**. راجِع القائمة، ثم اختر الصيغة. سهم الرجوع يعيدك للتحديد
كما تركته لتضيف أو تحذف ثم تعاين من جديد.

## 🖨️ الحقول المرسلة

من **⚙️ الإعدادات ← الحقول المرسلة** تختار ما يظهر في الطباعة والصورة
المُرسَلة. اسم العلاج واسم التحليل يظهران دائمًا، والباقي اختياري:

- **العلاجات:** الاسم العلمي، التصنيف، التركيز، الجرعات، مدة الاستخدام،
  الاستخدامات، المحاذير، ملاحظات — الافتراضي: الجرعات + الاستخدامات
- **التحاليل:** الرمز (المصطلح)، التصنيف (التخصص)، الهدف من التحليل،
  متطلبات التحليل، ممنوعات التحليل — الافتراضي: الرمز + المتطلبات
- **الوصفات:** التصنيف، النوع، الهدف، المواد المستخدمة، طريقة الإعداد، الاستخدام،
  الجرعة، مدة الاستخدام، الأعراض المتوقعة، الاحتياطات — الافتراضي:
  المواد + طريقة الإعداد + الجرعة

الاختيار يُحفَظ في قاعدة البيانات ويبقى بعد إغلاق التطبيق. الترتيب في
المخرجات ثابت ولا يتبع ترتيب النقر.

## ✅ ما يشتغل بالضبط
- إضافة/تعديل/حذف علاجات وتحاليل، مجمّعة بتصنيفاتها في أقسام قابلة للطي،
  مع بحث وسلة تحديد — كلها محفوظة في قاعدة البيانات المحلية فورًا
- نسخة احتياطية تلقائية يوميًا (أحدث خمس) مع **اختيار مكان الحفظ** واستعادة ومشاركة
- ترويسة طباعة اختيارية (اسم/صفة/تواصل) — فارغة افتراضيًا فلا تظهر
- **معاينة قبل الإرسال**: تبويب الورقة وتبويب الصورة، ثم إرسال بالصيغة
  التي تختارها — ما تراه في المعاينة هو ما يُرسَل حرفيًا
- **إرسال PDF مباشرةً** بلا مربع الطباعة، أو صورة، أو نص عادي للحافظة
- حقول النص الطويل تتمدّد مع المحتوى، ومعها إدراج نقاط وترقيم، والأسطر
  الجديدة تظهر كما كُتبت في الطباعة والصورة والنص
- طباعة/حفظ PDF للأقسام الأربعة عبر مربع طباعة أندرويد القياسي
  (`PrintManager` — لا نوافذ منبثقة، فهي لا تعمل داخل WebView أصلًا)
- **مشاركة كصورة ملف حقيقي** عبر أي تطبيق (واتساب وغيره) — بلا إنترنت
  (الصورة تُبنى محليًا بالكامل على الجهاز)
- استيراد/تصدير نسخة احتياطية (ملف JSON)
- قفل PIN اختياري لحماية فتح التطبيق

## 🔒 عن التوقيع
البناء أعلاه يُوقَّع تلقائيًا بمفتاح "debug" مؤقت (يكفي للتثبيت والاستخدام
الشخصي على جهازك). لو أردت لاحقًا توزيعه أو نشره رسميًا، استخدم من داخل
Android Studio: **Build ← Generate Signed Bundle / APK** وأنشئ مفتاح
توقيع خاص بك (خطوات قياسية موثّقة من جوجل).

## 📂 بنية المشروع
```
DaliliApp/
├── docs/                ← دليل المطوّر ومخطط قاعدة البيانات
├── tools/               ← الاختبارات وفحص الواجهة
├── dist/dalili.apk      ← ملف التثبيت الجاهز (اسم ثابت للرابط المباشر)
├── app/src/main/
│   ├── assets/          ← ملفات التطبيق (index.html + app.js + library.js)
│   ├── java/.../MainActivity.java   ← الغلاف الأصلي (WebView + الجسور)
│   ├── java/.../DaliliDb.java       ← قاعدة البيانات المحلية (SQLite)
│   ├── java/.../DbBridge.java       ← جسر JS ↔ قاعدة البيانات
│   ├── res/             ← الأيقونات والألوان والتخطيط
│   └── AndroidManifest.xml
└── gradlew / gradlew.bat  ← لا تحتاج Gradle مثبّتًا مسبقًا، هذا كافٍ
```

لتعديل نصوص/تصميم التطبيق نفسه: عدّل `app/src/main/assets/index.html`
و`app.js` مباشرة، ثم أعد خطوة البناء (٤).
